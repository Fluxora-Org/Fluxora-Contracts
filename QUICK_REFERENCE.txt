================================================================================
TESTING METHODOLOGY
================================================================================

FROZEN-CLOCK PATTERN (for Invariant I3):
  let vested_before = h.client.vested_of(&id);  // Fixed instant
  h.client.top_up(&id, amount);                 // NO time advance
  assert_eq!(h.client.vested_of(&id), vested_before);

This detects state transition bugs that time-advancing tests miss.

BOUNDARY VALUE ANALYSIS:
  • Lower: delta = 0 (rejected)
  • Boundary: delta = 1 (accepted)
  • Upper: u64::MAX (overflow)
