during the documentation consolidation in [#1681](https://github.com/Fluxora-Org/Fluxora-Contracts/issues/1681).

checklist and the original build spec. They are kept for provenance and are **not**
maintained. For current behaviour, read the documents in [`docs/`](../) and the test
suites they describe.
